# student-grade-calculator-

This Python program allows a user to enter a student's name and marks, then displays the corresponding grade based on the marks entered.

Features
Accepts the candidate's name.
Accepts marks as input.
Assigns grades according to the score:
A Grade: 90–100
B Grade: 80–89
C Grade: 70–79
D Grade: 60–69
Fail: Below 60
